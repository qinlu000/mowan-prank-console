# AstraChat 整蛊 MVP

一个本地运行的“假 LLM 聊天网站”：访客看到仿聊天助手页面，你在后台控制台实时查看消息并手动回复。

## 运行

```powershell
$env:ADMIN_PASSWORD="换成你的后台密码"
npm start
```

打开：

- 访客页：http://127.0.0.1:5173/
- 后台页：http://127.0.0.1:5173/admin.html

## 当前功能

- 访客聊天页面
- 后台会话列表
- 后台登录保护，密码通过 `ADMIN_PASSWORD` 设置
- 手动扮演 AstraChat 回复
- “正在输入”状态
- 访客发送后自动进入“正在思考”
- 后台回复会在访客端流式输出
- 访客端支持停止生成和重新生成
- 发送前延迟，制造生成中的感觉
- 更像 AI 输出的快捷回复模板
- “摊牌”按钮，向当前访客揭晓整蛊

## 注意

当前版本只把会话存在服务器内存里，重启后会清空。后续如果要长期使用，可以再加数据库、后台密码、真实 LLM 接管和部署配置。
